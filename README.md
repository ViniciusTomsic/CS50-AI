# CS50-AI
CS50’s AI with Python, offered by Harvard University, introduces the fundamentals of artificial intelligence and its real-world applications. The course covers key AI concepts, including:

Search algorithms (e.g., BFS, DFS, A*)

Knowledge representation and logic

Probability and Bayesian networks

Machine learning (supervised and reinforcement learning)

Neural networks and deep learning

Natural language processing

Students work on hands-on projects, implementing AI techniques in Python using libraries like TensorFlow and scikit-learn. The course balances theory with practical applications, making it ideal for beginners in AI.

For more details, visit: cs50.harvard.edu/ai
